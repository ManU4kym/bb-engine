🔧 CUSTOMIZE
════════════════════════════════════════════════════════════════════════════

Edit examples/config.yml:
  - http.rate_limit      (higher = faster but more aggressive)
  - http.max_concurrent  (more parallel requests)
  - http.timeout         (wait longer for responses)

Edit examples/wordlist.txt:
  - Add your own endpoints
  - Remove common ones you don't need
  - Optimize for your target

Edit examples/workflow.yaml:
  - Add/remove fuzzing modes
  - Adjust discovery depth
  - Customize stages

🐛 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

Report empty?
  → Check that assessment completed
  → Run: python generate_report.py again
  → Verify: bb-engine.db exists

Slow scanning?
  → Increase: http.max_concurrent in config
  → Use: quick mode instead of pipeline
  → Reduce: wordlist.txt size

Python not found?
  → Install: python3.7+
  → Check: python --version
